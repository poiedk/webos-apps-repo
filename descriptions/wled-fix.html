WLED Fix

WLED discovery and Hyperion recovery utility for rooted LG webOS TVs.

WLED Fix detects the active WLED controller on the local network, compares it with the Hyperion target and can repair the stored destination when the WLED address has changed.

  • Fast check of the current Hyperion target
  • ARP-assisted WLED discovery
  • Optional full /24 subnet scan
  • Updates Hyperion host and hostList values when needed
  • Creates a Hyperion database backup before changes
  • Supports multiple Hyperion instances
  • Can restart Hyperion after a repair
  • Optional post-repair verification and LED test
  • Simple and Advanced settings with configurable discovery behaviour

Requires root, Homebrew Channel, Hyperion.NG and WLED reachable on the same IPv4 network.
