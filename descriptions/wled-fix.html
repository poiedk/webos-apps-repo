WLED Fix

WLED rediscovery and Hyperion repair utility for rooted LG webOS TVs.

WLED Fix finds the active WLED controller on the local network and repairs Hyperion when its stored WLED address is no longer correct.

  • Fast check of the current Hyperion target
  • ARP-assisted WLED discovery
  • Optional full /24 subnet scan
  • Updates Hyperion host and hostList values
  • Creates a database backup before changes
  • Can restart Hyperion and verify the LED device afterwards
  • Simple and Advanced settings

Requires root, Homebrew Channel, Hyperion.NG and WLED on the same IPv4 network.
