WiFi Watch

Background Wi-Fi watchdog, diagnostics and safe recovery for rooted LG webOS TVs.

WiFi Watch monitors the TV network connection continuously, starts automatically after boot, records failures and can safely recover Wi-Fi when a real connectivity problem is confirmed.

  • Background watchdog that can start automatically after TV boot
  • Shows SSID, TV IP address, gateway status and gateway latency
  • Tracks RX dropped packets and short-term drop delta for the current watchdog session
  • Dashboard statistics reset on each new TV/watchdog boot session, while long-term recovery history remains available in Diagnostics
  • Monitors wlan0 state and ConnMan connectivity
  • Optional Auto Fix with recovery cooldown and loop protection
  • Manual quick recovery and full Wi-Fi restart
  • Boot grace period to avoid unnecessary recovery while Wi-Fi is still starting
  • Stores recovery history and the last failure snapshot
  • Captures routes, ARP, wireless state, ConnMan information and recent kernel messages for diagnostics

Requires a rooted LG webOS TV with Homebrew Channel. Auto Fix can be enabled or disabled from the application.
