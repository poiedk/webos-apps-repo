WiFi Watch

Wi-Fi monitoring and diagnostics for rooted LG webOS TVs.

WiFi Watch continuously checks the TV network connection and helps diagnose intermittent Wi-Fi failures without requiring SSH to stay connected.

  • Shows SSID, TV IP address and gateway status
  • Measures gateway latency
  • Tracks RX packets and dropped packets
  • Checks wlan0 operstate and ConnMan association
  • Captures routes, ARP, wireless status and recent kernel messages when a failure occurs
  • Keeps a rotating local diagnostic log

Version 0.1.0 is diagnostic-only and does not automatically restart networking.
